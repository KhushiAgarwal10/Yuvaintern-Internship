# Week 2 - Exploratory Data Analysis (EDA)

## Project Title

Agribusiness Crop Yield Exploratory Data Analysis

---

# Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the cleaned agribusiness dataset prepared during Week 1 of the internship. The dataset contains agricultural information such as rainfall, pesticide usage, average temperature, crop type, and crop yield values.

The primary goal of this task is to analyze the dataset visually and statistically in order to understand data distributions, relationships, patterns, trends, and anomalies. Various graphs and visualization techniques were used to gain insights into agricultural factors affecting crop yield.

---

# Objectives

* Understand the structure of the cleaned dataset
* Analyze distributions of numerical features
* Identify correlations between agricultural variables
* Detect patterns and anomalies in the data
* Generate meaningful insights using visualizations

---

# Dataset Used

Dataset Name:
cleaned_crop_dataset.csv

Dataset Features:

* Area
* Item (Crop Type)
* Year
* Average Rainfall
* Pesticides Usage
* Average Temperature
* Crop Yield

# Exploratory Data Analysis Performed

## 1. Statistical Summary

* Used describe() function
* Analyzed mean, standard deviation, minimum, and maximum values

## 2. Correlation Analysis

* Generated correlation matrix
* Created heatmap to identify relationships among features

## 3. Distribution Analysis

* Created histograms for numerical columns
* Analyzed data distributions

## 4. Outlier Analysis

* Used boxplots to detect extreme values
* Observed very few anomalies after preprocessing

## 5. Relationship Analysis

* Generated scatter plots
* Studied relationship between temperature, rainfall, and crop yield

## 6. Pairplot Visualization

* Visualized relationships between multiple numerical features

---

# Key Findings and Insights

* Crop yield is influenced by rainfall and temperature.
* Positive correlations exist between some agricultural variables.
* The dataset is normalized and well structured.
* Very few outliers are present after preprocessing.
* Numerical features show balanced distributions.
